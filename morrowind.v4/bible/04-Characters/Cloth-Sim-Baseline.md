# Draped cloth simulation — baseline backup

Baseline captured on branch `upstream-original-selector` before tuning the current Verlet cloth implementation.

This document records the pre-change implementation as a recovery reference. The executable source remains in `src/characters/clothSim.js`; this is a documentation checkpoint, not a replacement for that source file.

## Existing implementation

- `buildCloth(grid, pinRows)` creates particle positions, previous positions, base positions, pinned vertices, and structural/bending distance constraints from the draped garment grid.
- `stepCloth(cloth, dt, opts, core)` integrates Verlet motion under gravity and optional directional forces, clamps per-step displacement, repositions pinned vertices with the body, solves distance constraints, optionally applies a leg-bone-driven drape, then resolves collisions.
- Body collision is represented by a height-indexed elliptical torso/pelvis core from `pieces/draped.js`.
- Leg collision uses articulated, tapered capsules generated by `articulatedCapsules`; collision resolution runs after the constraints and can repeat for multiple passes.
- The ground plane is clamped with `groundY`.
- Current defaults in `stepCloth`: gravity `gy = -7.0`, Verlet damping `0.985`, collision standoff `0.030`, distance-constraint iterations `6`, per-step displacement cap `0.035`, and collision passes `6`.
- `pieces/draped.js` currently uses a geometry-generation standoff of `0.038` when creating draped garment grids.

## Intended style target

This is an old-school game presentation, not a physically exact cloth solver. Preserve the authored garment silhouette and keep motion restrained:

- small, readable secondary motion only; little movement while idle;
- modest lag on turns and steps, with quick, smooth settling;
- no conspicuous flapping, stretching, rubbery wobble, or large silhouette changes;
- body collision correctness takes priority over visible motion;
- collision should follow the existing character pose/rig and must not require per-animation hand-authored cloth behavior.

## Baseline known limitations

- The torso/pelvis collider is an ellipse sampled by height, not a full body mesh.
- Leg capsules cover thighs and shins, but do not model buttocks as a separate articulated volume.
- Constraint solving and collision projection are separate stages; a final collision projection can locally stretch constraints.
- This is a code-and-parameter baseline, not a visual acceptance claim. Runtime screenshots and movement tests are still needed after tuning.
