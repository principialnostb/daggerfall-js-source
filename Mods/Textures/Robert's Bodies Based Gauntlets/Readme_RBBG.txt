Robert's Bodies Based Gauntlets v0.1
===============================
by Pherim

The vanilla gauntlet meshes look terrible and are too small compared to the hands when using Robert's Bodies (possibly other body replacers as well). So this is an attempt to create improved gauntlet meshes that are based on the RB hands so that they would actually fit. This also fixes UV issues and makes them less blocky.

So far, only the Iron Gauntlets are covered! As I don't know when (or if) I'll do more, I'll just upload this as a WIP mod now.

They are based on Robert's bodies, but they are not required! This should work with all body replacers, including vanilla bodies. The only requirement is, if you want the left gauntlet to have the correct ground model, you need my Better Morrowind Armor Fixes (from the same mod page as this one)!

Installation
============
This is a pluginless replacer, so just copy the "meshes" folder into your "Data Files" folder and overwrite, if necessary. Or use a Mod Manager. The "Lefty" folder is only needed if you are also using Better Morrowind Armor Fixes, but it won't cause any issues if you don't.
