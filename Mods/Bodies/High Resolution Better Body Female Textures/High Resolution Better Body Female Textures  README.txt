    PLAYING & INSTALLING THE TEXTURES

*****************************************************************

This mod is a texture replacer for the mod Better Bodies which
developed from a desire by Cappucine to make body textures for the 
females from high resolution photgraphs for a more photorealistic
aesthetic.  Due to some other obligations, Cappucine was not 
able to finish the textures for a release, so she placed her confidance
in me (Westly) to take over the textures and get them ready for a release 
(by colouring them for the different races and adding touches that I would
deem necessary to work in Morrowind lighting conditions). After adding 
various details all my own, I can truly say that this was a team effort,
and am extremely greatful that Cappucine trusted me with the honour of 
picking up where she left off.  In addition to colouring and adding painted
details (like pores, goose bumps, freckles, highlights and shadows, etc), I
have also made unique underwear versions for each race as well as "Hirsute"
or hairier versions.  So, to reiterate, there are three versions in this 
download (nude without body hair, with body hair, and underwear).


Manual Installation:

Requires Better Bodies to be installed first (obviously)

Included in this mod are several folders, inside of each is a 
textures folder containing the proper textures for the corresponding
version of Better Bodies that you may use (Nude, Peanut Gallery, or Underwear).
These folders are named as follows (with their names describing the textures
therein):

Hands
Nude_Body_Hair
Nude_No_Hair
Underwear

The installation is simple and the same for each folder:

Open the folder for the textures that correspond to the
version of these new Better Bodies textures that you would 
like to use.

Inside you will find a Textures folder with the "bb" subfolder
nestled within (do not move any files out of these folders else
the replacer will not work properly).

Now find your game's Data Files folder.  This (if using the "C" drive)
is located at the following path: 
C:\Program Files\Bethesda Softworks\Morrowind\Data Files

Now copy the Textures folder from the Mod folder that you have 
chosen to open (for example from the Nude_Body_Hair folder) and paste
it into the game's Data Files folder.

You should then be prompted to overwrite the existing Textures folder
that already exists in your game's Data Files folder.  Choose yes/OK
to sucessfully overwrite this folder, and (if you have BB installed first)
you will now be able to see the new textures in game.

Again, the process is the same for each of the mod's included folders :) .

NOTES/CAVEATs:

1) Install the Hands folder first, as you will only have to do this
once as it is compatible with whatever other included body texture
folder that you decide to use.

2)If half way through your playing you decide to use another version of Better
Bodies, then, after you have installed Better Bodies again with the different
version, you must reinstall the textures from this mod that correspond 
to that new choice (as the existing Fit Body textures would be overwritten by
the original BB textures upon the new installation of BB).

3) These textures are very large (4x as large as the original 
BB textures).  As such, they might cause lag on some computers
(just fair warning).  I may make a smaller resolution version 
of these from my (Westly) source files, but for now these
are as they were intended when Cappucine initially started
the base textures.

4) Will I (Westly) make a male version of these?
Probably not in the near future, as these took quite a while to 
make themselves.  Having a great deal on my plate already, making 
a male version of these falls low on my priority list.  I am not
ruling them out, mind you, but they are not on my immediate to 
do list, that is for sure.
