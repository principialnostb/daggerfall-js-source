Description:
=========
The plug-in replaces the textures and body models of all Morrowind humanoid races
including argonians and khajiits on 'seamless'.

The paws of the beast are connected to the right foot, so now to them
all fashions with slinky underwear are also suitable.
(if only they need it :)

Compatibility:
==============
For better body docking, it is recommended to use BB compatible clothing.
For example, the Better Clothes project from Dereko.

If you wish, you can connect any other texture replacer of the beast,
It will replace the models of this fashion.

Some old or large plug-in packages containing better bodies
may conflict with this fashion. In this case, you need to restore the files
and fix the file date BetterBodies_1C.esp to a newer one.

This version uses feminine textures from the 'peanut gallery version'.
If you install another textures replacer, there may be a color inconsistency
women in the groin area. In this case, remove textures: bb_decalf_xx.dds

Connection:
============
Connection standard - register the archive "BetterBodies.bsa."

'Other' folder contains original descriptions and additional files
for the 'underwear' version.
