# Texture packs used by the Morrowind branch

Large third-party texture/model packs are intentionally not stored in this branch to keep the working tree manageable. The integration code and configuration are preserved, but the local `Morrowind Textures/` asset directory must be supplied separately when running the game.

## Upstream mod pages

- [Simply Walking (Remastered)](https://www.nexusmods.com/morrowind/mods/49785) — source for the walking/running animation set being evaluated.
- [OpenMW Dynamic Actors](https://www.nexusmods.com/morrowind/mods/54782) — NPC/player idle animation and camera/dialogue features. This is an OpenMW Lua mod, not a drop-in animation pack for this JavaScript project; use it as a reference for behavior and animation assets only unless compatibility is implemented.

Keep downloaded mod archives outside this repository. Respect each mod author's permissions and install requirements.
