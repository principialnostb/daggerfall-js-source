# EMC и Pixelation: правила сопровождения

Это действующие правила пользовательского меню Enhanced Mod Compatibility (EMC), его раздела Textures и отдельной вкладки Pixelation. История реализации и технические подробности находятся в [Enhanced-Mod-Compatibility.md](Enhanced-Mod-Compatibility.md). При расхождении старого описания интерфейса с этим документом актуальные правила приведены здесь. Изменять фактические зависимости следует одновременно с кодом и этой таблицей.

Меню — самостоятельный дизайн DFO Online. Референс управления модами: [DFU ModManager](https://github.com/Interkarma/daggerfall-unity/blob/master/Assets/Game/Addons/ModSupport/ModManager.cs), его включение ресурсов и порядок модов. Мы добавляем каталог групп ресурсов, отдельные настройки внешнего вида и локальный RU/EN; это не копия окна DFU. Настоящее обновление оформления не меняет загрузчики и порядок ресурсов.

## Структура и ответственность

- EMC: «Тела и анимации», «Окружение», «Текстуры». Pixelation остаётся отдельной соседней вкладкой.
- Каталог перечисляет модификации, а не тестовые варианты отдельных анимаций. Стабилизированные значения скрытых настроек остаются в сохранённом профиле.
- Переключатель RU/EN общий для EMC, Textures и Pixelation; хранится в `emcLanguage`. Он не переключает язык остальной игры.
- Morrowind People и Billboard Look остаются собственными настройками игры в Mods & files. Не включать их в стандартизированный профиль.
- Числовые уровни Pixelation сохраняются: HD = 0, Light = 540, Medium = 360, Classic = 270, Retro = 200. Менять название не значит мигрировать значение.

## Состояния ресурсов

Не смешивать три состояния: ресурс подключён, пользователь включил функцию, функция фактически доступна. Количество файлов подтверждает обнаруженные пути, но не гарантирует совместимость каждого меша или клипа.

| Состояние | Действия карточки |
| --- | --- |
| Ресурс не подключён | Скачать с Nexus Mods, если ссылка известна; подключить ресурсы |
| Ресурс подключён, в том числе из текущей сборки | Выбрать источник заново; удалить ресурсы |
| Ресурсы группы полностью подключены | Разрешить переключатель всей группы |
| Не хватает компонента | Показать список компонентов с текстовыми статусами; включение группы недоступно |
| Встроенная самостоятельная функция | Включить/отключить; скачивание не требуется |

Зависимые компоненты группы не получают отдельные переключатели включения. Импорт и удаление источника остаются отдельными действиями карточек. Отключение группы не удаляет файлы. Удаление ресурсов отключает импортированную копию или помечает встроенный источник отключённым, не удаляя исходные файлы с диска. Не менять этот контракт ради одинакового вида кнопок.

## Обязательные и необязательные зависимости

Источник истины — функции доступности в runtime. UI читает те же функции; запрет только через CSS или `disabled` недостаточен. Обработчик и загрузчик тоже должны учитывать отключение.

| Возможность | Условия применения |
| --- | --- |
| Модификации на основе Morrowind | Подключённые 3D-ресурсы Morrowind в Mods & files |
| Группа модификаций | Все объявленные компоненты подключены; переключатель группы включён |
| Редактор улучшенного персонажа | Доступна группа «Тела и руки» |
| Paperdoll Enhanced и кастомизация 2D | Активен 2D-инвентарь; у каждой функции собственное включение |
| Базовая кастомизация 2D | Paperdoll Enhanced не обязателен; он улучшает изображение |
| Базовая кастомизация 3D | Собственный переключатель; улучшенные тела и дополнительные наборы не обязательны для базового выбора доступных моделей |
| Анимация стандартных плащей | Включены кастомизация 3D и анимация плащей. Группы тел и боевых анимаций не обязательны |
| Дополнительные облики брони и оружия | Кастомизация 3D, полная активная группа «Тела и руки», переключатель соответствующего набора и доступные файлы |
| Дополнительные облики плащей | Те же условия плюс включённая анимация плащей |
| Пикселизация рук, игрока и NPC | Полная активная группа «Тела и руки» |
| Пикселизация предметов и декора | Не зависит от группы тел |
| Женские текстуры высокого разрешения | Для применения нужна основа Better Bodies |
| Complete Armor Joints | Для применения нужен Better Morrowind Armor |

Последние два условия сейчас объясняются текстом в Textures; это не новые блокировки источников. Их загрузка остаётся прежней. Не объявлять состояние готовности по одному нажатию на вариант источника.

Обязательные условия показываются списком: зелёная галочка и пояснение для выполненного, красный крест и конкретное действие для невыполненного. Сетевые ограничения обозначаются отдельно. Необязательные улучшения оформляются нейтральным блоком «Дополнительные улучшения» и статусами «Используется» / «Не используется». Отсутствие необязательного улучшения не блокирует базовую функцию. Подсказка объясняет вклад дополнения; обязательная причина недоступности всегда видна без наведения.

## Сохранения, кэш и отключение

Сохранённый выбор и применяемый внешний вид — разные данные. Отключение связанных ресурсов переводит модель, портреты, paperdoll, щиты и анимации на доступный резервный вариант. Сохранённый вариант не должен продолжать влиять через кэш и не должен приводить к пустому телу, если его файлов нет. При включении выбор возвращается, если соответствующий ресурс существует.

Ключи кэша учитывают профиль активных ресурсов и внешности; запоздавшие асинхронные результаты старого профиля отбрасываются. Использовать существующие `modResourceSignature`, `noteModPresentationChanged` и active-appearance helpers, а не очищать всё хранилище браузера.

Исключение, явно выбранное владельцем: выключение кастомизации paperdoll очищает сохранённые 2D-облики предметов, включая старое поле шлема. Сохранённый выбор лица игнорируется при отключении и может возвращаться при включении. Выбор 3D-обликов и параметры редактора не стирать из-за временно отсутствующей зависимости. Индикатор кастомизации предмета скрывается, если обе кастомизации выключены; одна доступная вкладка 2D/3D занимает всю ширину, две делят её.

## Правила Textures

Каждый из восьми существующих наборов — карточка с названием, назначением, авторством, известным условием применения и действиями управления ресурсами. Некоторые наборы поставляют также меши и плагины: не описывать их как исключительно картинки.

По уточнению владельца от 2026-11-08 прежний контрол Original / Vanilla / «Этот набор» удалён из карточек. Вместо него используются кнопки:

- Ресурсы не подключены: только «Скачать с Nexus Mods» и «Подключить ресурсы».
- Ресурсы подключены: только «Включить» / «Отключить» по текущему состоянию и «Удалить ресурсы». Скачивание и подключение скрыты. Сетевые ограничения сохраняются.
- После удаления карточка снова показывает скачивание и подключение. Исходные файлы с диска не удаляются.

Сохранённые значения источников 0/1/2 остаются совместимыми: существующий Vanilla читается как прежде, явное включение записывает 2, отключение — 0. Не вызывать setter при отрисовке или смене RU/EN. Не применять глобальное переосмысление Vanilla к телам или анимациям. Подключение и удаление используют общее хранилище EMC. Изменения применяются после перезапуска, о чём сообщает вступление. Прежних пояснений выбора Original / Vanilla / «Этот набор» в меню больше нет.

## Авторство и описание

Внешний мод: исходный автор или авторы, отдельно «Интеграция: BLOODBATH». Работа по подгонке, щитам, порядку анимаций и совместимости внутри связки относится к интеграции; не создавать ради неё отдельный полноценный мод-переключатель. Полностью самостоятельная механика без участия чужих модификаций: «Автор: BLOODBATH». Непроверенного автора не угадывать.

Описание сообщает, что меняется, где это видно, границы поддержки и зависимости. Для кастомизации обязательно указать локальность внешнего вида, ограничения по материалу/весовому классу/типу и различие вкладок 2D/3D. Для одежды учитывать поднятый и опущенный капюшон. Не обещать сетевой передачи выбранного облика. Для Skyrim-наборов указывать необходимые локальные файлы Skyrim SE; текст о пути не выдавать за реализованный диалог импорта. Игровые ресурсы не коммитить.

## Визуальное оформление и RU/EN

Прямоугольные карточки, тёмный фон, тонкая латунная рамка и шрифт игры. Золотой заголовок `#dbb86b`; текст `#b9b39f`; авторы `#a8b6ce`; интегратор `#f0cc78` с отдельным акцентом. Положительный обязательный статус `#8fc49a`, отсутствующий `#ed9a78`. Действия: включение — зелёный, отключение — золотой, подключение — приглушённый синий, удаление — тёплый красный.

Не использовать цвет как единственный сигнал. Сохранять читаемость причины недоступности, даже когда кнопки затемнены. Не превращать необязательное дополнение в красную ошибку. Группировать короткие подписи, переносить их на узком экране, не раздвигать окно длинным названием. Не вставлять управляющие символы в CSS `content`; использовать обычный Unicode или DOM-текст. Статусы дополнений должны читаться без расшифровки значков.

Любое новое видимое сообщение, состояние, подсказка и описание добавляются одновременно на RU и EN. Названия модификаций и имена авторов не переводить произвольно. Языковой переключатель не должен менять настройки ресурсов. Описание и семантика доступности должны совпадать на обоих языках.

## Проверка перед передачей

Проверить RU и EN, узкую ширину и длинные подписи; подключённый, отключённый и неполный набор; сохранённый выбор после выключения/включения; отсутствие нежелательного влияния кэша. Для Textures подтвердить, что значения источников не меняются при отрисовке и переводе. Для Pixelation подтвердить три заблокированных контрола при отключённой группе и независимость декора. Обязательные и необязательные условия проверить раздельно.

Ближайшие проверки: `emcLanguage.test.js`, `pixelationPresentation.test.js`, `texturePresentation.test.js`, `pixelationAvailability.test.js`, `extraAppearance.test.js`, `cloakDependencies.test.js`, `enhancedModResources.test.js`, `inventoryPresentation.test.js`. Запускать также проверку типов и ESLint изменённых файлов. Проверка оформления в браузере не является проверкой анимаций и моделей в игре; такую проверку отмечать отдельно. Перед push действуют полные требования AGENTS.md.


## Чистый локальный EXE без обновлений

`npm run dist:clean` собирает Windows x64 portable в `app/release-clean/DFO-Online-Clean-win-x64-portable.exe`. Перед первым запуском сборки установить зависимости: `npm ci` и `npm ci --prefix app`.

Команда сохраняет изменения кода и EMC, но исключает ресурсы из `Mods/` на этапе сборки Vite. Шаблоны загрузчиков остаются зарегистрированы, поэтому ресурсы можно подключить через EMC позднее. Встроенные ресурсы самой игры за пределами Mods остаются частью игры. Это не сборка upstream без изменений.

Упаковка происходит в отдельном каталоге `.proving-ground/clean-desktop-*`; исходные папки ресурсов не переименовываются и не удаляются. В упакованной оболочке выключены автоматические и ручные пути обновления, нет game-seed.json и конфигурации публикации. Используется отдельный appId и каталог данных Daggerfall JavaScript Clean. Обычная сборка dist:mod остаётся отдельной и продолжает включать моды и канал обновлений форка.

Проверки логики сборки: `test/tooling/cleanDesktop.test.js`. Подготовленная команда сама по себе не означает, что EXE уже собран или проверен запуском.


## Онлайн-установщик для тестировщиков

`npm run dist:install` создаёт небольшой Windows x64 установщик NSIS Web и отдельный сжатый пакет игры в `app/release-testers/testers-<timestamp>/`. Установщик скачивает этот пакет с закреплённого релиза GitHub; последующие автообновления оболочки и игры выключены. Он создаёт обычную установку с ярлыками и удалением программы. Перед передачей тестировщикам требуется опубликовать и EXE, и `.nsis.7z` из `publication.json` в указанном там релизе. Один EXE без опубликованного пакета не является готовой поставкой.

В пакет входят ресурсы, которые используют загрузчики Mods, кроме High Resolution Better Body Female Textures, Westly's Faces Refurbished и Better Bodies 3.2. Ненужные Atlas Textures не читаются загрузчиком. Ресурсы уже встроены: отдельный ZIP ветки resources и ручной импорт этих наборов для такой установки не требуются. Собственные игровые файлы Morrowind и ARENA2 по-прежнему подключаются через обычные окна.

Фильтр ресурсов применяется к основной сборке и к worker-сборкам: последние не должны затягивать browser-only Mods через поднятые Vite eager-glob импорты. До этого worker-сборки обходили фильтр dist:clean, поэтому прежний большой portable EXE нельзя считать проверенной чистой поставкой. Исправление проверяется реальной сборкой fixture с Worker. Маленький EXE не означает маленький общий объём: размер пакета публикуется отдельно.


Название поставки — DFO Online Test Build. appId и каталог Daggerfall JavaScript Testers сохраняются ради существующих установок. В поставку дополнительно включён Paperdoll Enhanced как включённый shipped-мод в общем реестре текстур; его индекс готовится при сборке, а картинки декодируются общим пулом dfmod. Paperdoll не переключает режим инвентаря.

Режим инвентаря — единый источник для фигуры и значков: оба флага morrowind3dPaperDoll/morrowind3dInventoryIcons читаются из morrowindThirdPersonOnly. Старые противоречивые сохранённые флаги больше не удерживают 2D при выбранном 3D. Проверка включает первую отрисовку и перезагрузку; браузерный tools/inventoryModeProbe.mjs использует настоящий UI и сохранение, но подставной провайдер картинки модели, поэтому не является проверкой NIF-геометрии.

Сохранения из TEST_SAVES_PATH (локально C:/Users/user/Desktop/Saves) упаковываются только в эту тестовую поставку. При первом старте копируются отсутствующие слоты целиком; существующие не перезаписываются. Маркер первого копирования сохраняет последующее удаление игроком тестового слота. Исходные сохранения не изменяются и не коммитятся.
