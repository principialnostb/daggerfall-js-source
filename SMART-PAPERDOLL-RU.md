# Smart PaperDoll — установка и откат

Smart PaperDoll добавляет необязательный режим объёмного персонажа в существующую карточку Skin. Он использует **готовый RGBA-композит слоёв фигуры без фонового SCBG** из `src/ui/paperDoll.js`, а не повторно собирает слои экипировки. Фон убран, чтобы задний план бумажной куклы не превращался в сплошную стенку вокселей. Поэтому в модель попадают те же цвета, броня, одежда и замены текстур, что и в бумажной кукле инвентаря.

## Что меняется

- Новый переключатель `Graphics.SmartPaperDoll` в настройках Eye Of The Beholder. По умолчанию выключен.
- Кнопка Smart PaperDoll в существующей карточке Skin.
- Новый `src/characters/paperDollVoxel.js`: ресэмплинг RGBA, альфа-маска, цветные воксельные ячейки с глубиной и кэш по версии композита.
- Третье лицо сначала пробует Smart PaperDoll. Если режим выключен или композит ещё не готов, текущий рендерер персонажа остаётся резервным.
- Первое лицо не изменяется. При смене композита модель пересобирается автоматически по `version`.

## Проверка

Требуется Node.js версии, указанной в `package.json` (20.19+ или 22.12+).

```powershell
npm test -- --test-name-pattern="Smart PaperDoll|voxel"
npm run lint
npm run build
```

Если проект использует собственный раннер тестов, запускайте обычный `npm test` — новые тесты находятся в `test/characters/`.

## Откат

1. В карточке Skin выключите Smart PaperDoll.
2. Чтобы полностью убрать изменение кода, верните файлы к состоянию до ветки `feature/smart-paperdoll-voxel` либо отмените её коммиты. Переключатель выключен по умолчанию, поэтому обычный рендерер сохраняется без дополнительных действий.

Изменение не добавляет зависимости и не требует сторонних ассетов.
