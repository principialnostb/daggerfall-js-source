# Smart PaperDoll — статус и следующий этап

## Важное исправление

Упрощённый процедурный манекен не является реализацией Smart PaperDoll и удалён. Игровой путь отрисовки восстановлен до версии ветки `smart-paperdoll`; манекен больше не подключён к персонажу. Существующая кнопка `SMART PAPERDOLL: ON/OFF` не изменялась.

## Цель следующей реализации

Собрать отдельного женского персонажа на основе штатного Light Warrior: сохранить пропорции, силуэт, ракурсы и анимационный характер оригинала, но сделать тело и предметы экипировки самостоятельными слоями.

Для этого сначала требуется найти и извлечь исходные кадры/ресурсы женского Light Warrior и установить, какой путь в движке формирует его направления и анимации. Затем нужно создать согласованный набор тела и одежды на базе этих ресурсов. Процедурная геометрия без сверки с оригиналом не считается приемлемым результатом.

## Безопасность текущей ветки

- Переключатель Smart PaperDoll сохранён без изменений.
- Отрисовка персонажа восстановлена до прежнего поведения.
- Ветки `main` и `smart-paperdoll` не менялись.
- Следующая реализация должна быть проверена тестами и визуально в игре до объявления готовой.


## Инструмент разбора исходного архива

В ветке добавлен `tools/paperdoll/inspectEnhancedArchive.mjs`. Он извлекает `paperdoll enhanced.rar`, проходит вложенные RAR/7z/ZIP-архивы и формирует `build/paperdoll-source/manifest.json` с путями, размерами PNG и границами непрозрачных пикселей. Исходные игровые файлы не меняются.

Запуск из корня репозитория (нужен установленный `7z`, `7zz`, `unar` или `unrar`):

```sh
node tools/paperdoll/inspectEnhancedArchive.mjs
```

Для другого пути/папки вывода:

```sh
node tools/paperdoll/inspectEnhancedArchive.mjs --archive "paperdoll enhanced.rar" --out build/paperdoll-source
```

Это подготовительный инструмент для инвентаризации реальных текстур, не готовая модель и не включение новой отрисовки. Следующий этап — сопоставить извлечённые текстуры с экипировочными слоями и штатными направлениями/кадрами, затем собрать тело и слои без процедурного манекена.
