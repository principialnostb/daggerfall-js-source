# Полный комплект: Белый волк / Классика / Чёрный волк

Автоматическая косметическая палитра 3D-комплекта Skyrim iron, зависит от реально надетого волчьего плаща. Без него либо при wolf-brown (название в UI: Классика) используется прежний комплект. Wolf-white выбирает холодный светлый металл и светлую серо-бежевую кожу; wolf-black — тёмную сталь и угольную кожу. Ни статы, ни item.variant, ни 2D-иконки не меняются.

Сохраняется выбранная модель каждой части: перекрашиваются только iron_* и steel_plate_helm_horned. Обычные стальные plate-модели и другие комплекты не заменяются на железные автоматически. При двух волчьих плащах приоритет имеет первый валидный в порядке worn pieces. Выбор цвета плаща уже вызывает rebuildForLook; надевание/снятие проходит обычный путь пересборки экипировки. Дополнительный переключатель темы не нужен.

Runtime: wolfArmorPalette.js выбирает палитру; composeWornArmor подставляет модель с тематическими текстурами до обычной сборки. Это общий путь для видимых частей/первого и третьего лица. Если новые локальные NIF отсутствуют, браузер сохраняет исходную часть вместо пропавшей брони. Тело, лицо, меховой плащ и его физика не перекрашиваются.

Сборка: node tools/skyrim/buildWolfArmorPalettes.mjs. Нужен уже импортированный железный комплект. Из 11 исходных NIF делаются 22 тематических NIF, из четырёх атласов — восемь DDS с mipmaps. Имена wolf_armor_* исключены из Git. Меши меняются только в строках путей текстур: вершины, веса, UV, материалы и анимационные привязки побайтно сохраняются.

Текстуры создаются воспроизводимым преобразованием: мягкая маска тёплой цветности отделяет кожу/рога от нейтрального металла, сохраняет различия яркости, исходные потёртости и alpha. Это приближённая художественная маска, а не ручная разметка UV-материалов. Оригинальные текстуры не перезаписываются. При переимпорте железного сета повторить сборку палитр.

Проверки: wolfArmorPalette.test.js проверяет надевание/снятие/Original, ограничение только железными моделями, сохранение всех байтов NIF кроме путей текстур и контраст палитр. Локальная часть теста пропускается без импортированных ассетов. Для превью previewWolfCloak.mjs / renderWolfCloak.py поддерживают переменные WOLF_ARMOR_PALETTE=classic|white|black, WOLF_PREVIEW_OUT и WOLF_PREVIEW_VIEWS=front,back. Рендеры scratch/wolf-armor-{classic,white,black} — Blender-инспекции реальных runtime-posed мешей, не скриншоты из игры. Новые цвета ещё требуют визуальной проверки при игровом освещении.

Уточнение палитры: металл сохраняет исходный RGB и получает лишь небольшой сдвиг яркости (white: 0.96×канал+12, black: 0.92×канал). Кожа/тканевые области сохраняют сильную тематическую перекраску. Шлем целиком исключён из маски кожи: его тёплые участки — рога, и они получают только мягкий сдвиг вместе с металлом, сохраняя натуральный оттенок. Это заменяет прежнее сильное осветление/затемнение железа. Проверка palettePixel отдельно ограничивает изменение металла/рогов и подтверждает сильную перекраску кожи.
