## Что принято и что сохранить

- Железный комплект Skyrim с рогатым шлемом уже был в equipment до этой работы. Сохранены его модели, привязки и существующая система смены 3D-облика.
- Wolf Pelt Cloak: сохранена принятая пятислойная геометрия; бурый, белый и чёрный варианты доступны всем четырём шаблонам плащей. Пользователь отверг последующие художественные переделки и явно попросил оставить эту модель.
- В Vanilla Animated добавлено движение тяжёлой шкуры, гибкость свободных концов и заметная бегущая волна ветра. Финальный эффект пользователь назвал идеальным. Не заменять его слабым idle-only колебанием и не применять тканевую деформацию напрямую ко всем меховым слоям.
- Выбор лица в инвентаре — косметический 2D, не смена расы, пола или головы 3D-персонажа. Три карточки в ряду, перелистывание, отдельная полоса над фигурой без сдвига слотов брони. Увеличено заполнение портретов; DOM карточек и загруженные лица переиспользуются.
- У установленного paperdoll enhanced.dfmod есть женские лица, но нет мужских FACE00–07. Мужские используют доступный штатный арт; отсутствующие ресурсы не подменяются Morrowind-рендерами. Загрузчик сможет использовать мужской addon, если его предоставить.
- INFO перенесена выше карточек облика у всех предметов.
- Original для плащей использует текущую 2D-картинку paperdoll с окраской, при неудаче — исходную Morrowind-иконку.
- Механика щитов оставлена заготовкой по решению пользователя. Есть строгий каталог совместимости типа/материала; отсутствие альтернатив у большинства щитов ожидаемо. Не разрешать баклер вместо большого щита ради наполнения списка.
- Для обычного шлема два независимых раздела: 3D-модель и 2D-облик. Второй меняет и иконку, и слой на бумажной кукле, сохраняя характеристики и выбранную 3D-модель в мире.

## Настройки и область действия

Настройки хранятся в существующей локальной полке dagger.ui.v1 через uiPrefs.js, а не в новых игровых характеристиках:

| Ключ | Область действия |
|---|---|
| inventoryFaces | имя персонажа + раса + пол |
| mwCloakLooks | шаблон плаща; classic / wolf-brown / wolf-white / wolf-black |
| mwArmorLooks | существующие модели брони; щиты дополнительно shield:<template>:<material> |
| mwSteelHelm | существующий выбор 3D-шлема |
| helmetPaperdollLooks | шаблон 107 + материал, целые 0–5; отсутствие означает исходный вариант предмета |

Эти облики не являются уникальными для каждого предмета и не синхронизируются как серверные предметные данные. Два шлема одного материала разделяют локальный 2D-выбор. Артефакты исключены. Пол/раса определяют архив; материал — окраску. Нельзя записывать косметический выбор в item.variant: он используется другими системами.

## Стабильность карточки

При смене облика retainAppearanceCard сохраняет DOM открытой .packtip, её якорь, прокрутку и фокус. render переиспользует её, не пересоздаёт detailCol и не запускает повторное позиционирование; updateAppearancePreview меняет только большую иконку. Рамка выбранной 3D-карточки меняется сразу, затем rebuildForLook обновляет риг. 2D-выбор обновляет композицию без перестройки 3D-рига. Остальные действия карточки сбрасывают сохранение; другой предмет и изменение раскладки при resize также сбрасывают его.

Вкладки используют штатные .act/.primary. Превью обрезаются по alpha; результат кэшируется. Отдельные поправки масштаба по дизайну компенсируют гребни/рога: open/horned 3D оставлены прежнего размера, closed увеличен; 2D-купола уменьшены относительно шлемов с гребнями. Это ручная калибровка для текущих дизайнов, а не универсальное распознавание головы. После нового арта перепроверить пропорции.

## Проверки и оставшаяся визуальная приёмка

Целевые тесты: helmetPaperdollLooks, inventoryFace, shieldLooks, wolfCloak, mwwolfpeltmotion, paperdollloadidentity, paperdollart, characters/paperdoll. Проверяются независимость 2D/3D, сброс Original, материал/форма щитов, NIF cutout/skin round trip, реальная локальная геометрия и ветер/инерция/коллизии. Проверка типов: npm run types. Проверка стиля: npm run lint. Полный CI/сборка не заявлены выполненными; итог конкретного запуска см. Equipment-Validation.md.

Ручная проверка перед следующими изменениями:

1. В инвентаре нажать обе вкладки, перелистать все ряды 2D-шлемов, выбрать несколько 2D/3D-вариантов и Original. Карточка не должна менять положение, мерцать или сбрасывать прокрутку/фокус.
2. Сравнить видимый размер купола, а не границы гребня/рогов; проверить разные пол/расы и изменённый масштаб UI. Три карточки и стрелки должны помещаться.
3. Убедиться, что 2D-иконка и надетый слой согласованы, 3D в мире независима, материал/статы не изменены.
4. Проверить лица и отсутствие скачков при кликах на вкладки инвентаря/слоты/вещи; проверить узкое окно.
5. Проверить три меховых цвета в Vanilla Animated: покой, ходьба, бег, поворот, остановка, бой, возврат из свёрнутой вкладки. Учесть грубые коллизии и возможный клиппинг с навешенным оружием/щитом.

Исторические картинки из scratch не считать новым игровым результатом. Не обещать физику отдельных волос, гарантированное отсутствие клиппинга или полное соответствие AI-концепту.
