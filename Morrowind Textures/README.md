# Morrowind texture packs

This branch intentionally does not bundle the large Morrowind texture archives.

**Texture-pack files (kept on the texture branch):**
- [Open the Morrowind Textures folder on `morrowind.v3`](https://github.com/principialnostb/daggerfall-js-source/tree/morrowind.v3/Morrowind%20Textures)

The runtime integration and code in this branch are kept separately from the bulk assets. If you clone this branch, the texture files will not be present locally; download the packs separately and place them according to the paths expected by the project.

## Animation mods being evaluated

- [Morrowind Animation Overhaul (150 New Animations)](https://www.nexusmods.com/morrowind/mods/60253)
- [Animation Blending](https://www.nexusmods.com/morrowind/mods/53779) — MWSE version; engine-specific, not a drop-in library for this browser renderer.
- [Simply Walking (Remastered)](https://www.nexusmods.com/morrowind/mods/49785)
- [Female animation option candidate](https://www.nexusmods.com/morrowind/mods/43129)

Review compatibility and asset permissions before bundling third-party animation files into this repository.
