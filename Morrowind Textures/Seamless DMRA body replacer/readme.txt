1. Requirements: 

a) This is a a sexy body conversion mod based on Better Bodies 2.2 by Psychodog Studios team. So, to enjoy this mod, you need to install their body mod first. 
b) If you want to see  realistic body skin effects on your female characters, you need to install OpenMW and Cappucine & Westly's Extra High Resolution Female Textures first. 
c) If you want to see DMRA beasts, you need to install Slof's Better Beasts 1.1 first. 
d) If you want to see some realistic skin effects on characters' faces, you need to install OpenMW and Motoki's Better Heads 2.0 first.

2. Installation Order: 

a) Now there is two main files (one is for Better Bodies 2.2 users and the other one is for Better Heads 2.0 users) and  one optional texture set in the download section. Download the main files first and install them manually or automatically (via NMM).

For New HD Better Heads Textures, 
¡æ All contents in the "\Textures" folder should go to Morrowind game's same directory, i.e., "..\Morrowind\Data Files\Textures" folder.

c) More Wet Body Texture Sets for Cappuccine & Westly's Extra High Resolution Female Textures will be ready for download very soon. See the screenshots for more information. To see the in-game effect, you need to run Morrowind with OpenMW engine. 
d) DMRA body replacer for Slof's Better Beasts will be ready for download very soon. 
e) A Wet Body Texture Set for Slof's Better Beasts will be ready for download very soon. 

================================= 

3. OpenMW shader setting: (Googling is recommended for beginners) 

a) Find OpenMW configuration file (settings.cfg) in "\My Documents\My Games\OpenMW" folder. 
b) Open it with a text editor. 
c) Insert following command lines 

[Shaders]
auto use object normal maps = true
auto use object specular maps = true
auto use terrain normal maps = true
auto use terrain specular maps = true
normal map pattern = _n
normal height map pattern = _nh
specular map pattern = _spec
force shaders = true
clamp lighting = false

d) Save the file. 

=================================

3. Final step: 

a) Run OpenMW 
b) Click "Run Settings Importer" button in the "Settings" tab 
* Step 3-b is not neccessary.. but I have included here just in case for beginners. 
c) Click play and enjoy the game! :)
