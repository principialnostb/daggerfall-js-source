MORROWIND ANIMATION OVERHAUL (MAO)
Version: v0.72
Author: Parsoma

DESCRIPTION

Morrowind Animation Overhaul is an extensive third-person animation
replacer for The Elder Scrolls III: Morrowind.

The mod currently replaces 150 animations, covering character movement,
combat, spellcasting and other actions.

Every animation was recreated manually from scratch for Morrowind.
I tried to make the animations look and feel similar to those in Oblivion,
my second favorite game in the series. I've always loved its animations,
and personally, I think they look much better than the ones in Oblivion Remastered.

The goal of the project is to make character movement feel more natural
and expressive while preserving the overall feel and character of the
classic Elder Scrolls games.

The mod replaces animations for walking, running, turning, jumping and
sneaking, as well as a large number of combat animations for hand-to-hand
combat, one-handed weapons, two-handed weapons, two-handed wide weapons
and bows.

IMPORTANT

This mod replaces third-person animations only. First-person animations
are not affected.

The animations are intended for humans, elves and orcs. Khajiit and
Argonians are currently not supported, as they use a separate animation
set.

INSTALLATION

Copy

xbase_anim.kf
xbase_anim_female.kf

to:

Morrowind\Data Files\Meshes

and replace the existing files if prompted.

If you already have another mod installed that modifies xbase_anim.kf
and xbase_anim_female.kf, it is recommended to make a backup of those
files before installing Morrowind Animation Overhaul.

RECOMMENDATIONS

For smoother transitions between animations, I recommend using Animation
Blending.

Animation Blending - MWSE:
https://www.nexusmods.com/morrowind/mods/53779

Animation Blending - OpenMW:
https://www.nexusmods.com/morrowind/mods/53842

These mods provide smoother blending between different character
animations and work particularly well with Morrowind Animation Overhaul.
